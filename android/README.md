# Rishe Android

این پوشه پوسته Android اپلیکیشن ریشه را برای ساخت APK بازار نگهداری می‌کند.

- Application ID: `store.rishe.app`
- Web App: `https://rishe.smarbiz.sbs/`
- Debug artifact: `rishe-android-test`
- Signed release artifact: `rishe-bazaar-release`

نسخه release فقط با Secrets امضای Android ساخته می‌شود. کلید امضا باید برای همه نسخه‌های بعدی ثابت و امن نگهداری شود.
