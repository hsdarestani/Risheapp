# اپلیکیشن ریشه

PWA گیمیفای‌شده برای خانواده‌های ایرانی، با هویت برند «مستقیم از مزرعه پدری».

## قابلیت‌های نسخه فعلی

- داشبورد امتیاز، ماموریت روزانه و streak
- «چی بپزم» بر اساس مواد موجود و زمان
- آموزش و آزمون شناخت کیفیت برنج، عسل، چای و حبوبات
- بازی کوتاه امتیازی «حجره‌دار کاربلد»
- اتصال خواندنی به WooCommerce Store API سایت `rishe.store`
- کیف پول و جریان درخواست تضمین قیمت (پرداخت واقعی هنوز نیازمند اتصال درگاه است)
- جست‌وجوی مقایسه‌ای در ترب و دیجی‌کالا
- گالری مسیر تامین، بخش سفیر ریشه و همکاری در فروش
- ثبت درخواست «عودت به شرط پخت» با کد رهگیری و ذخیره پایدار روی سرور
- PWA قابل نصب روی موبایل

## اجرا در توسعه

```bash
npm install
npm run dev
```

فرانت‌اند روی `5173` و API روی `3000` اجرا می‌شود.

## اجرا با Docker

```bash
cp .env.example .env
docker compose up -d --build
```

## استقرار

Workflow گیت‌هاب با Secrets زیر روی سرور deploy می‌کند:

- `HOST`: آدرس سرور
- `PASS`: رمز root

پورت پیش‌فرض `80` است و داده درخواست‌های عودت داخل volume داکر نگهداری می‌شود.

## نکات فاز بعد

- ورود با OTP و اتصال حساب کاربر به WooCommerce
- شارژ واقعی کیف پول، قرارداد پیش‌خرید و تحویل مرحله‌ای
- API رسمی/قراردادی برای مقایسه خودکار قیمت؛ بدون scraping شکننده
- پنل مدیریت عودت، سفیران، محتوا و ماموریت‌ها
- آپلود عکس/فیلم واقعی مزارع و نقاط تامین
