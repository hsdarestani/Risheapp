# اپلیکیشن ریشه

PWA گیمیفای‌شده برای خانواده‌های ایرانی، با هویت برند «مستقیم از مزرعه پدری».

## قابلیت‌های نسخه فعلی

- داشبورد امتیاز، ماموریت روزانه و streak
- «چی بپزم» بر اساس مواد موجود و زمان
- آموزش و آزمون شناخت کیفیت برنج، عسل، چای و حبوبات
- بازی کوتاه امتیازی «حجره‌دار کاربلد»
- اتصال خواندنی به WooCommerce Store API سایت `rishe.store`
- کیف پول و جریان درخواست تضمین قیمت (پرداخت واقعی هنوز نیازمند اتصال درگاه است)
- جست‌وجوی مقایسه‌ای در ترب و دیجی‌کالا
- گالری مسیر تامین، بخش سفیر ریشه و همکاری در فروش
- ثبت درخواست «عودت به شرط پخت» با کد رهگیری و ذخیره پایدار روی سرور
- PWA قابل نصب روی iPhone و Android
- پوسته Android برای ساخت APK قابل انتشار در بازار

## اجرا در توسعه

```bash
npm install
npm run dev
```

فرانت‌اند روی `5173` و API روی `3000` اجرا می‌شود.

## اجرا با Docker

```bash
cp .env.example .env
docker compose up -d --build
```

Caddy روی پورت‌های `80` و `443` قرار می‌گیرد و برای دامنه `rishe.smarbiz.sbs` گواهی HTTPS را خودکار دریافت می‌کند. داده درخواست‌های عودت داخل volume داکر نگهداری می‌شود.

## استقرار وب‌اپ

Workflow گیت‌هاب با Secrets زیر روی سرور deploy می‌کند:

- `HOST`: آدرس سرور
- `PASS`: رمز root

دامنه تولید:

```text
https://rishe.smarbiz.sbs
```

### نصب روی iPhone

وب‌اپ را در Safari باز کنید، دکمه Share را بزنید و گزینه `Add to Home Screen` را انتخاب کنید. اپ با آیکن ریشه و حالت مستقل از مرورگر اجرا می‌شود.

## ساخت APK بازار

پروژه Android داخل پوشه `android/` قرار دارد و Workflow با نام `Build Rishe Android APK` یک APK آزمایشی می‌سازد.

برای ساخت نسخه release امضاشده و قابل انتشار در بازار، این Secrets را در GitHub اضافه کنید:

- `ANDROID_KEYSTORE_B64`: فایل keystore به‌صورت Base64
- `ANDROID_KEYSTORE_PASSWORD`: رمز keystore
- `ANDROID_KEY_ALIAS`: نام کلید
- `ANDROID_KEY_PASSWORD`: رمز کلید

خروجی release در Artifact با نام `rishe-bazaar-release` قرار می‌گیرد. شناسه اپلیکیشن Android برابر `store.rishe.app` است؛ کلید امضا باید برای تمام به‌روزرسانی‌های بعدی نگهداری و پشتیبان‌گیری شود.

## نکات فاز بعد

- ورود با OTP و اتصال حساب کاربر به WooCommerce
- شارژ واقعی کیف پول، قرارداد پیش‌خرید و تحویل مرحله‌ای
- API رسمی/قراردادی برای مقایسه خودکار قیمت؛ بدون scraping شکننده
- پنل مدیریت عودت، سفیران، محتوا و ماموریت‌ها
- آپلود عکس/فیلم واقعی مزارع و نقاط تامین
